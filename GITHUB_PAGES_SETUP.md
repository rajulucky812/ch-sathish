## 🔧 Step-by-Step Deployment

### **Step 1: Upload Files to GitHub**

1. Go to your repository: https://github.com/rajulucky812/ch-sathish
2. Click **"Add file"** → **"Upload files"**
3. Upload these 3 files:
   - ✅ `index.html`
   - ✅ `style.css`
   - ✅ `script.js`
4. Click **"Commit changes"**

### **Step 2: Enable GitHub Pages**

1. Go to your repository
2. Click **Settings** (⚙️ icon)
3. In left sidebar, click **"Pages"**
4. Under "Build and deployment":
   - **Source:** Select "Deploy from a branch"
   - **Branch:** Select "main" (or your default branch)
   - **Folder:** Select "/ (root)"
5. Click **"Save"**

GitHub will now deploy your site automatically.

### **Step 3: Wait for Deployment**

- GitHub takes 1-5 minutes to build your site
- You'll see a green checkmark ✅ when ready
- A message will appear: "Your site is live at:"

### **Step 4: Access Your Portfolio**

Your portfolio will be available at:
```
https://rajulucky812.github.io/ch-sathish/
```

## 🆘 Troubleshooting

### **Issue: 404 Error**
**Solution:** Make sure you uploaded `index.html` to the root directory

### **Issue: Site not loading**
**Solution:** 
- Clear browser cache (Ctrl+Shift+Delete)
- Wait 5 minutes for GitHub to rebuild
- Check Settings → Pages shows green checkmark

### **Issue: Styling looks broken**
**Solution:** Make sure `style.css` is in the same directory as `index.html`

### **Issue: Links don't work**
**Solution:** Ensure all links point to correct sections (e.g., `#about`, `#experience`)
